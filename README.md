# 🌦 Weather App

A responsive weather application that shows real-time weather data using OpenWeather API.

## 🚀 Features
- Search any city
- Real-time temperature
- Humidity & wind speed
- Responsive design

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeather API
